사용설명서

처음 쓰는 사람도 순서대로 누르면 됩니다.

1

앱 받기

홈페이지 접속 → 회원가입 → 로그인 → 다운로드 → 설치

2

기본 사용

조 선택 → 달력 확인 → 날짜 터치 → 근무 또는 메모 입력

3

알람 설정

앱 설정 → 알람설정 → 필요한 근무 알람 ON

4

업데이트

앱 설정 → 업데이트 확인 → 새 버전 안내 → 다운로드 후 설치

5

문의 / 요청

가입자 익명 요청함 → 기능 추가 또는 오류 신고 작성

30초 요약

홈페이지 접속 → 회원가입 → 로그인 → 다운로드 → 설치

업데이트는 앱에서 설정 → 업데이트 확인

안내

이 앱은 개인 편의를 위해 제작한 비공식 앱입니다.

실제 근무표와 공식 공지를 우선 확인해 주세요.
