화이팅 GitHub Pages 배포 안내

예상 주소:
https://lts7364.github.io/hwaiting-app/

1. GitHub에서 repository 생성
   Repository name: hwaiting-app
   Public 권장

2. 이 ZIP을 압축 해제

3. Android Studio에서 GitHub용 앱 ZIP을 release 빌드

4. 나온 APK 파일명을 아래로 변경 후 files 폴더에 넣기
   hwaiting-v1-0-91-code92-k7p4x9.apk

5. repository 루트에 전체 파일 업로드
   index.html, login.html, download.html, request.html, admin.html, version.json, firebase-config.js, files/

6. repository Settings > Pages
   Source: Deploy from a branch
   Branch: main
   Folder: /root
   Save
